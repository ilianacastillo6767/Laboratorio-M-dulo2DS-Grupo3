Consejos de Maquillaje

Consejos básicos de maquillaje

Antes de maquillarte es importante:

  • Lavar el rostro
  • Aplicar crema hidratante
  • Usar protector solar
  • Colocar primer para que el maquillaje dure más

Elegir la base correcta

La base debe parecer natural y combinar con el tono de tu piel.

  • Probar la base en el cuello
  • Piel grasa: usar base mate
  • Piel seca: usar base hidratante

Uso del corrector

El corrector ayuda a cubrir:

  • Ojeras
  • Manchas
  • Granitos

Tips

Usa un corrector un poco más claro que tu piel para iluminar la mirada.

Maquillaje de ojos

Para un look natural:

  • Sombras claras
  • Delineado fino
  • Máscara de pestañas suave

Para un look elegante:

  • Sombras oscuras
  • Efecto smokey eyes
  • Pestañas más marcadas

Labiales

Colores recomendados:

  • Nude maquillaje natural
  • Rojo elegante
  • Rosa juvenil

Consejo

Exfolia tus labios antes de aplicar labial para un acabado más suave.
